# Security policy

Report suspected vulnerabilities through the repository's
[GitHub private vulnerability reporting](https://github.com/stufently/ai-browser-gateway/security/advisories/new).
Keep vulnerability details in the private report until a fix and disclosure
have been coordinated with the maintainer.

Include the affected version or commit, the impact, and minimal reproduction
steps using sanitized examples. Do not attach tokens, proxy addresses, proxy
credentials, or configuration files containing them. Remove secrets and private
network details from logs and screenshots before sharing them.
