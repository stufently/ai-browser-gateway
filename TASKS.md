- [ ] **Токен Cloudflare API + поддомен под свой стенд.** Домен — из тех, что уже

- [ ] **Решение по Cloudflare Browser Rendering.** Аккаунт CF у владельца уже
  есть, значит managed-браузер от самого Cloudflare открывается API-токеном и
  стоит копейки. Это единственный способ померить Tier 4 по-настоящему, а не по
  прайс-листу.

  биллинг-напоминалка). Даёт замер того, что реально решает смена egress: один и
  тот же провайдер с хостинг-IP против резидентского. Без этого колонка «прокси»
  в таблице останется теоретической.
- [ ] **Какие ещё боевые цели из рабочих проектов добавить.** Сейчас взяты
  `bizprofile.net` (снят с мониторинга check-sites из-за CF, возврат намечен на
