  **Мой хвост после захода:** пометить происхождение каждого правила детектора
  МАШИННО (поле в таблице правил: измерено на фикстуре / предположение), а не
  комментарием. Правило `captcha` не измерено ни на одном живом теле; без такой
  пометки через две вехи оно будет читаться как факт, и на нём построят
  следующее. Тест обязан требовать: правило-предположение не даёт вердикт в
  одиночку, а у `measured` названа КОНКРЕТНАЯ фикстура и её файл существует —
  иначе через три вехи файл переименуют, ссылка умрёт, а пометка «измерено»
  останется, и строгость станет видимостью строгости.
  Правило «эскалируем по `content_missing`» держится на умении отличить пустую
  страницу от заглушки: **обе приходят с непустым телом**. Порог по длине текста
  их НЕ разделяет — измерено на настоящих телах: у заглушки Cloudflare 58 символов
  видимого текста, у JS-шелла 8. Разделяют только положительные маркеры челленджа
  (title, `challenges.cloudflare.com`, `cf-chl*`, `noindex,nofollow`, заголовок
  `cf-mitigated`): на фикстурах у заглушки их три, у двух остальных ноль.
  Настоящие тела уже лежат в `tests/fixtures/` — детектор проверяется на них, а не
  на выдуманном `<div>`. Замечание координатора, и оно верное: без этого раннер
  будет уходить в браузер на каждом блоке и потеряет весь выигрыш фазы 1.

  месяц включено, дальше $0,09/час ≈ $0,25 за 1000 страниц. Без токена строка
  остаётся «не измерено».
- [ ] **Креды GoldProxy.** Самый ценный незакрытый замер фазы 1: наш хост сидит на

  не справился» от «адрес не пустили» без второго egress нельзя**. У gpt-web-gateway
  это уже измерено: один образ, один отпечаток, разные адреса — 200 и 403.
- [ ] **Живой URL рилса для цели `login-instagram`.** Я подставил id наугад, и
  замер это поймал: все провайдеры получили тайтл `Post isn't available` — строка
  меряет мёртвую ссылку, а не стену авторизации, и помечена `valid = false`. Нужен
  конкретный публичный рилс из тех трёх задач бэклога, ради которых цель и взята.
- [ ] **Какие ещё боевые цели из рабочих проектов добавить.** Сейчас взяты
