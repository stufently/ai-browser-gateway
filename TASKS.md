## За владельцем (я сам сделать не могу)

- [ ] **Токен Cloudflare API + поддомен под свой стенд.** Домен — из тех, что уже
  в Cloudflare и ведутся через octodns (`~/github/ansible`, репо octodns); запись
  кладётся штатным флоу octodns, не руками в панели. Даёт воспроизводимый
  CF-стенд: Managed Challenge и Turnstile на официальных тестовых ключах. Пока
  токена нет — фаза 1 идёт на чужих целях, стенд подключается позже.
- [ ] **Токен Cloudflare для Browser Run.** Аккаунт CF у владельца уже есть, значит
  managed-браузер от самого Cloudflare открывается API-токеном: 10 browser-hours в
  месяц включено, дальше $0,09/час ≈ $0,25 за 1000 страниц. Без токена строка
  остаётся «не измерено».
- [ ] **Креды GoldProxy.** Самый ценный незакрытый замер фазы 1: наш хост сидит на
  хостинговом ASN без репутации (`AS206996 ZAP-Hosting`), и **отличить «инструмент
  не справился» от «адрес не пустили» без второго egress нельзя**. У gpt-web-gateway
  это уже измерено: один образ, один отпечаток, разные адреса — 200 и 403.
- [ ] **Какие ещё боевые цели из рабочих проектов добавить.** Сейчас взяты
  `bizprofile.net` (снят с мониторинга check-sites из-за CF, возврат намечен на
  12.09.2026), `instagram.com` (три задачи бэклога упираются в стену логина) и
  магазины hqd как контроль «чистый nginx».
