## Что мутировать

Четыре решения, каждое ровно одной мутацией, все в
`bench/providers/docker/probe.py`:

1. **NUL → U+FFFD** в значении атрибута (мутант: NUL удаляется, как было до
   вехи). Ожидание: падает тест, который требует `none` на
   `src="…render=explicit<NUL>"`.
2. **Деление `class` только по ASCII-пробельным** `[ \t\n\f\r]+` (мутант:
   обычный `.split()`, режущий и NBSP, и вертикальную табуляцию). Ожидание:
   падает тест на `class="g-recaptcha<NBSP>foo"`.
3. **Обратный слэш = разделитель пути** в `src` (мутант: замена не делается).
   Ожидание: падает тест на `src="recaptcha\api.js?render=explicit"`.
4. **Порядок нормализации**: NUL→U+FFFD, затем удаление `\t\n\r`, затем
   `\`→`/`, затем обрезка краёв (мутант: обрезка краёв ПЕРЕД удалением
   `\t\n\r`). Ожидание: падает тест, который различает порядок. Если такого
   теста нет — это survivor, и он главный результат прогона.

Для каждого: id, соответствие пункту, diff, SHA256
исходника/мутанта/восстановления, доказательство активации (мутант РЕАЛЬНО лёг
— проверяется до запуска тестов), команда/cwd/rc, лог, упавший тест и строка
assertion. Мутант, который НЕ убивается своим тестом, — главная находка.
Equivalent — только с доказательством.
