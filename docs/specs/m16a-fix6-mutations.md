## Что мутировать

Тринадцать решений, каждое ровно одной мутацией
(`bench/providers/docker/probe.py`, кроме двух последних — `gateway/format_html.py`):

1. отсечение фрагмента `#` ДО разбора query в `src`;
2. разделение query только по `&` (не по `[&;]`);
3. регистрозависимое сравнение имени параметра `render=`;
4. отсутствие `strip()` у значения `render=`;
5. точное имя пути `recaptcha/api.js` (не суффикс);
6. разбор `src` только у тега `script`;
7. `data-sitekey` на любом теге (мутант: только `div`/`script`);
8. деление class-токенов по любому пробельному символу (мутант: `split(" ")`);
9. охрана `or ""` у boolean-атрибута `class`;
10. обязательный `#` в регулярке числовой ссылки (детектор);
11. непустая последовательность цифр в той же регулярке (детектор);
12. обязательный `#` в регулярке форматтера;
13. непустая последовательность цифр в регулярке форматтера.

Для каждого: id, соответствие пункту выше, diff, SHA256
исходника/мутанта/восстановления, доказательство активации, команда/cwd/rc,
лог, упавший тест и строка assertion. Мутант, который НЕ убивается своим
тестом, — главная находка прогона. Equivalent — только с доказательством.

Отдельно ответить на вопрос «верно ли закреплено поведение» по трём осям,
которые выглядят спорно: `data-sitekey` на `img`/`input` считается
интерактивным виджетом; `<iframe src="recaptcha/api.js?render=explicit">`
интерактивным НЕ считается; `<div class></div>` на 403 даёт `access_denied`.
