## Что мутировать

Два решения, каждое ровно одной мутацией, оба в
`bench/providers/docker/probe.py`:

1. **Схема решает, заменять ли `\` на `/`** (мутант: замена безусловная, как в
   fix8). Ожидание: падает тест, который требует `none` на
   `src="data:text/javascript,//recaptcha\api.js?render=explicit"` при HTTP 200
   с CF-меткой.
2. **Из дублирующихся атрибутов берётся ПЕРВЫЙ** (мутант: обход `attrs` в
   прямом порядке, то есть побеждает последний). Ожидание: падает тест на
   `<div class="foo" class="g-recaptcha"></div>`.

Для каждого: id, соответствие пункту, diff, SHA256
исходника/мутанта/восстановления, доказательство активации (мутант РЕАЛЬНО лёг
— проверяется ДО запуска тестов), команда/cwd/rc, лог, упавший тест и строка
assertion. Мутант, который НЕ убивается своим тестом, — главная находка.
Equivalent — только с доказательством.
