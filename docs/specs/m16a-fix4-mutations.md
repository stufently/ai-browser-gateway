Суть правки: `int(строка)` в CPython отказывается разбирать больше 4300 цифр
(лимит считает и ведущие нули), `html.unescape` зовёт его на каждой десятичной

тело с `&#<много цифр>;` роняло форматы `markdown`, `links` и `meta`, и API
отвечал HTTP 500. Клипование заменяет заведомо out-of-range ссылки на U+FFFD
до подачи разметки в парсер. Максимальный кодпоинт 0x10FFFF = 1114111, семь
десятичных цифр; восемь значащих не влезают никогда.

⚠️ **Шестнадцатеричные ссылки намеренно НЕ трогаются**: лимит цифр действует
только для оснований, не являющихся степенью двойки, `int(s, 16)` не падает
ни на какой длине, а `html.unescape` сам отдаёт U+FFFD на значении вне
диапазона. Мутант, добавляющий hex-ветку, неубиваем по построению — не
заводить.
