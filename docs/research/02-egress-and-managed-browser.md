## Cloudflare Browser Run — аккаунт у владельца уже есть

`developers.cloudflare.com/browser-rendering/platform/pricing/`:

| | Workers Free | Workers Paid |
|---|---|---|
| Browser hours | 10 минут в сутки | **10 часов в месяц**, далее **$0,09/час** |
| Одновременных браузеров | 3 | 10 (в среднем за месяц), далее $2,00/браузер |

В наших единицах. Страница за Cloudflare берётся браузером примерно за 10 секунд,
то есть один browser-hour ≈ 360 страниц:

- **включено:** 10 часов ≈ **3 600 страниц в месяц бесплатно** (при подписке
  Workers Paid $5/мес);
- **сверх того:** $0,09 / 360 ≈ **$0,25 за 1000 запросов**.

Это на два порядка дешевле любого unblocker-API и не требует нового вендора:
аккаунт Cloudflare у владельца есть, нужен только API-токен.

**Но это браузер, а не unblocker.** Ротации прокси у него нет, выходит он из сети
самого Cloudflare, и **пройдёт ли он Managed Challenge чужого сайта — неизвестно
и здесь не измерено.** Проверяется одним токеном; пункт стоит в `TASKS.md`.

| Способ | $/1000 запросов | Success rate |
|---|---|---|
| Cloudflare Browser Run, сверх включённых часов | ≈ 0,25 | **не измерено** |
| Cloudflare Browser Run, в пределах 10 ч/мес | 0 | **не измерено** |

## Прокси — GoldProxy у владельца тоже уже есть

Прокси у владельца есть, по нему ходит биллинг-напоминалка. Это единственный
способ измерить, **что реально решает смена egress**: тот же провайдер с
хостинг-IP против резидентского.

Почему это самый ценный незакрытый замер фазы 1. У `gpt-web-gateway` уже измерено
(26.07.2026): один и тот же образ с одним отпечатком получает `200` с одного
адреса и `403 cf-mitigated: challenge` с другого. Наш хост сидит на
`AS206996 ZAP-Hosting GmbH` — хостинговый ASN без репутации. Значит все наши
провалы на bizprofile.net могут объясняться адресом, а не инструментом, и
**отличить эти два объяснения без второго egress нельзя**.

Пока замера нет, строка «прокси» в сводной таблице остаётся теоретической, а все
выводы фазы 1 про Cloudflare сопровождаются оговоркой про egress. Пункт в
`TASKS.md`.

## Что это меняет в архитектуре

Лестница брифа «дешёвый запрос → браузер → платный API» теряет последнюю ступень.
Остаётся:

```
обходной вход (RSS, sitemap, API, архив) →
HTTP с браузерными заголовками →
свой браузер →
свой браузер через свой прокси →
Cloudflare Browser Run →
человек
```

Первая ступень стоит первой не по красоте: измерено, что Wayback отдаёт живой
снимок bizprofile.net за тот же день, когда ни curl, ни playwright+stealth эту
страницу не берут (см. `03-stand-b-results.md`).
