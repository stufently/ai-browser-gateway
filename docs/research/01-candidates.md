# Инвентарь кандидатов — проверено по реестрам 06.09.2026

Источник затравки — приложенный владельцем чат ChatGPT
(`chatgpt.com/share/6a9d9e26…`). Оттуда взяты **имена кандидатов**, и только они.
Всё остальное в чате (версии, даты релизов, номера CVE, авторство) в этой таблице
**не воспроизводится**: каждая строка ниже получена запросом к PyPI/GitHub API в
день составления. Расхождения с чатом отмечены — их достаточно, чтобы не доверять
чату как источнику фактов.

Команды-улики: `curl -fsS https://pypi.org/pypi/<pkg>/json`,
`curl -fsS https://api.github.com/repos/<owner>/<repo>`.

## Платные (desk-research, замера НЕ будет)

Решение владельца 06.09.2026: регистраций и карты не трогаем. В сводной таблице
у этих строк колонка success rate остаётся **пустой с пометкой «не измерено»** —
заявленные вендором 99,9 % и наш замер это величины разной природы, смешивать их
в одном столбце нельзя.

Список к прайс-разведке: ZenRows, ScrapingBee, ScraperAPI, Zyte, Scrapfly,
Bright Data, Oxylabs, Decodo, Nimble, Firecrawl Cloud.

Два ресурса у владельца **уже есть** и почти бесплатно закрывают этот пробел —
вынесено в `TASKS.md` как решение за ним:
аккаунт **Cloudflare** (значит Browser Rendering открывается API-токеном) и
**GoldProxy** (прокси, по нему уже ходит биллинг-напоминалка).

## Обходные входы (отдельный класс, не «провайдер»)

RSS/Atom, `sitemap.xml`, JSON-эндпоинты самой страницы, официальные API сайта,
кэш поисковиков, Wayback Machine, Common Crawl, `r.jina.ai`. Меряются на тех же
целях: доля целей, где обходной вход вообще существует, — это самая дешёвая
строка всей таблицы, и она может оказаться выше любого браузера.

## Что из этого следует для стека

Наблюдение, ради которого таблица и собиралась: **шесть кандидатов отсеиваются
без единого запроса.** По мёртвости — `undetected-chromedriver` (последний релиз
02.2024), `tls-client` (02.2024), `hrequests` (12.2024). По лицензии,
несовместимой с сетевым сервисом под пермиссивной, — `nodriver` и `zendriver`
(AGPL-3.0), `rnet` (GPL-3.0). Замер начинается не с чистого листа.

Отдельно про AGPL-проекты `trawl` и `Byparr`: встраивать их нельзя, **мерить
можно и нужно** — они запускаются как отдельный сетевой сервис и служат эталоном
«а лучше ли наш каскад чужого готового».

И главная поправка к затравке: чат ошибся в версии или дате **у каждого**
кандидата, который я проверил (pydoll, invisible-playwright, trawl, camoufox).
Ни одно число из него в проект не переносится.
