# M2 runner implementation plan

> Execute the approved specification with test-first steps, using
> superpowers:subagent-driven-development for the independent container task
> and superpowers:requesting-code-review for final review.

**Goal:** A reproducible provider matrix runner and JSONL report, with no host dependencies.
**Architecture:** Registry and plan are pure data; an injected launcher executes
one container per item. M1 owns evaluation, records and coverage. A standalone
container probe normalizes seven providers; CLI connects these components.
**Tech Stack:** Python standard library; provider dependencies only inside images.
**Spec:** `docs/specs/m2-runner.md` (provided and approved for execution by user).

## Constraints

- Work only in the supplied clone on `m2-runner`; preserve every protected M1 file.
- Preserve all 75 existing tests and 17 mutation definitions.
- No Docker build, live provider/network requests, or fabricated benchmark figures.
- Include supplied specification in the task commit; commit and normal push.
- Copy acceptance commands mechanically from the spec into `report.json`.

- [x] Containers (independent delegate): seven Dockerfiles and common probe, with
  injected/fake browser tests proving blank-before-timer and one target navigation.
  Use the exact Xvfb, primp and pydoll facts from the spec. No host installation.
- [x] Extend mutation gate by at least six required defects, then run all tests
  and all mutants. Review the complete change and address actionable findings.
- Delivery: commit only scoped work; execute all eight acceptance commands verbatim,
  write eight evidence entries, push current branch normally, confirm clean tree.

## Interface decisions

- Image tags: `abg-<provider>:m2`; container selector: `ABG_PROVIDER` environment.
- `argv_extra` contains Docker options before image, URL and sentinel follow image;
  execution appends `--mode`. Local scenario cells request host networking.
- Entrance providers have cold items only; wayback is registry-only for the next
  milestone and is excluded from default seven-provider runs.
- CLI defaults to stand A at `http://127.0.0.1:8000`, one cold and one browser warm
  sample, 20-second pauses. Explicit target TOML honors its 30-second host pause
  and one-request rule. Invalid targets are skipped.
- Probe metrics absent after launch failure use the M1-required zero numeric
  placeholders and are excluded from report latency/RSS summaries; errors remain
  in coverage. Metadata absent from actual observation is always `unknown`.
